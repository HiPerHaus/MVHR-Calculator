# Owner-supplied MVHR units
In Draw, choose the actual unit model and set **Unit supply → Owner supplies unit**. For an existing unit, right-click it and choose **Mark unit as owner-supplied**; use **Include unit in supply** to reverse it. Decentralised units use the same right-click action. Newly placed units default to included even if the prior unit was owner-supplied.

The supply choice is per component in the active design option. It is saved, copied with markup and undoable. It leaves the unit, handing, connection points, CW arrangement, airflow and engineering evidence unchanged. It does not declare a unit supplied, compatible, warranted or installed. Verify the exact model, configuration and condition before installation. Owner-supplied units are identified on the drawing and in a separate non-purchase section of the parts PDF and CSV; they are excluded from costing readiness and HiPer OS purchase items. Separately listed controls, CW parts, drains, ductwork and other accessories remain in the supply scope unless separately agreed. No project was changed by adding the control.
