# Installation reference illustration refinement

The 9 November 2026 owner request was to make the installation references closer to the five supplied source images. The reusable SVG renderer in `src/sheets/install-reference-illustrations.mjs` replaces the generic silhouettes with source-shaped linework: hatched ceiling and wall sections, the TVA fitting bracket and grille profile, flanged Q mounting-set bodies, AeroFresh service panels and port faces, condensate drains, and the AF300 overhead duct break.

The source dimension endpoints and values remain the same. Unknown Q drain allowance and all AF300 assembly dimensions stay blank, with explicit notes. No electrical terminals, cable ratings or wiring specification have been inferred. The source screenshots remain outside the repository. These pictorial references do not change model geometry, quantities, clearance requirements, equipment selection or installation approval.

The owner approved the separate A3 engineering-style installation detail sheet on 9 November 2026. It follows each plan, before the A4 parts list. The 10 November owner correction moves that compact TVA and housing dimension information beside the respective fitting on the following sheet; no terminal detail strip remains on the plan. Applicable equipment illustrations move to that detail sheet, freeing plan space. A clearly labelled conceptual insulation section shows the layer relationship only; project material, thickness, R-value and vapour-control details remain not specified. It does not prescribe additional insulation on already insulated duct.

Verification uses the full repository checks, build and `scripts/browser-plan-details.mjs`. That script checks the real PDF renderer, vector text, A3 landscape/portrait and A4 page sizes, global all-options page numbering, browser print pagination, and text bounds in the five-reference stress layout in both orientations. Its synthetic fixtures are not a real design validation.
