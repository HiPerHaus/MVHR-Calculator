# Ceiling and volume foundations (18 November 2026)

Optional additive fields: `floor.ceiling` (shared floor default), `room.ceiling` (option-specific override), `project.ventilationReference` (shared whole-dwelling reference inputs). Older saved projects remain valid without these fields, with untouched stored height evidence. When no floor ceiling field exists, the derived estimate uses an explicitly labelled assumed 2.5 m; it is not a verified measurement. Explicit unknown floor/room settings remain unknown, and explicit floor, room and legacy heights retain priority. This fallback does not write any saved heights, targets or PHPP inputs. Existing explicit legacy room height is retained until a room setting is explicitly saved. Existing targets and legacy `volumeEvidence` are untouched. No schema bump: these are optional draft inputs, not engineering authority. Older clients may preserve but do not interpret these fields; do not edit ceiling/reference settings with older clients. Room volume is derived afresh, never stored as a certified result.

Flat ceilings use area × height. A single-plane rake uses low/high heights at the room polygon projection extrema along an explicit low-to-high plan direction. Integrating this linear height field at the area centroid gives the exact polygon-prism volume. An irregular room does not generally use (low+high)/2. Multiple slopes, ridges, stepped ceilings, void deductions and openings need separate review and are explicitly unsupported. Missing/stale room boundaries or unknown heights remain unknown. Floors total confirmed room geometry only, not an automatically complete building envelope. Current area is wall-reference-line area, not measured clear/net area; actual-height volume is a geometry estimate, not certified net air volume, Vn50 or TFA.

PHI source reviewed 18 November 2026: https://passipedia.org/planning/building_services/ventilation/differentiation_between_vv_and_vn50_values . Residential ventilation reference Vv is TFA × 2.5 m, independent of actual height; its 0.3/h reference must not be applied to the taller actual volume automatically. The UI asks for separately reviewed whole-dwelling TFA and source. A transparent planning comparison shows that reference alongside occupancy × a stated 30 m³/h/person design assumption. Occupancy guidance: https://passipedia.org/planning/building_services/ventilation/basics/air_volumes . Neither reference is a complete validated allocation method. No room targets are overwritten; extract requirements, transfer paths, room allocation, local rules and certifier review remain separate gates. No compliance, certification, unit-selection or commissioning claim is made.

Tests cover flat/raked/irregular geometry, missing/invalid heights, inheritance, overrides, legacy heights, stale rooms, serialization, separate TFA and target preservation. Live saved projects are not used for testing.
